Willkommen beim Komponenten Viewer

Wählen Sie oben ein Projekt und dann eine HTML-Datei aus.

So funktioniert's:

  1. Markdown schreiben: Erstellen Sie Ihr Pitch-Deck als Markdown
  2. LLM konvertieren: Lassen Sie ein LLM das Markdown zu HTML konvertieren
  3. Speichern: HTML in output/ Ordner speichern
  4. Auswählen: Datei oben im Dropdown auswählen
  5. Screenshot: Komponenten einzeln screenshotten
💡 Screenshot-Tipps:
  • Breite: Auto, Schmal, Mittel, Breit, Voll
  • Chrome: DevTools → Element → Screenshot
  • Firefox: Rechtsklick → Screenshot des Knotens
  • Tastatur: Strg/Cmd + ←/→ für Breite
