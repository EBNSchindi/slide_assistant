# GitHub Design Guide

Dieser Style Guide basiert auf dem GitHub Design System.

## Farben

- **Primärfarbe:** #238636 (GitHub Green)
- **Hintergrund:** #ffffff (Weiß)
- **Text:** #24292f (Dunkelgrau)
- **Rahmen:** #d0d7de (Hellgrau)

## Typografie

- **Schriftart:** System Font Stack (Apple, Segoe UI, Helvetica, Arial)
- **Überschriften:** 600-700 Gewicht
- **Text:** 400 Gewicht

## Komponenten

- **Border Radius:** 6px
- **Padding:** 48px für Komponenten
- **Schatten:** Leichte Schatten für Tiefe

## Verwendung

Dieser Style wird automatisch geladen, wenn "GitHub Design" im Style-Dropdown ausgewählt wird.
