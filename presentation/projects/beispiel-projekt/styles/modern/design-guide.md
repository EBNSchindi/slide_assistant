# Modern Design Guide

Dieser Style Guide bietet ein modernes, cleanes Design mit blauen Akzenten.

## Farben

- **Primärfarbe:** #0066cc (Modern Blue)
- **Hintergrund:** #ffffff (Weiß)
- **Text:** #1a1a1a (Dunkelgrau)
- **Rahmen:** #e0e0e0 (Hellgrau)

## Typografie

- **Schriftart:** Inter (mit Fallback auf System Fonts)
- **Überschriften:** 600-700 Gewicht
- **Text:** 400 Gewicht

## Komponenten

- **Border Radius:** 8px (größer als GitHub)
- **Padding:** 48px für Komponenten
- **Schatten:** Moderate Schatten mit Hover-Effekten
- **Transitions:** Smooth Animationen (0.3s ease)

## Besonderheiten

- Hover-Effekte mit leichter Transformation
- Modernere Farbpalette
- Weichere Schatten
- Größere Border-Radius Werte

## Verwendung

Dieser Style wird geladen, wenn "Modern" im Style-Dropdown ausgewählt wird.
