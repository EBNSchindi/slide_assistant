# Minimal Design Guide

Dieser Style Guide bietet ein minimalistisches, cleanes Design ohne Schatten und mit reduzierten Farben.

## Farben

- **Primärfarbe:** #666666 (Grau)
- **Hintergrund:** #ffffff (Weiß)
- **Text:** #1a1a1a (Dunkelgrau)
- **Rahmen:** #e5e5e5 (Sehr helles Grau)

## Typografie

- **Schriftart:** System Font Stack
- **Überschriften:** 500-600 Gewicht (leichter als andere Styles)
- **Text:** 400 Gewicht

## Komponenten

- **Border Radius:** 4px (kleiner als andere Styles)
- **Padding:** 48px für Komponenten
- **Schatten:** Keine Schatten
- **Border:** Dünnere Borders (1px statt 2px)

## Besonderheiten

- Keine Schatten für flaches Design
- Reduzierte Farbpalette (hauptsächlich Grautöne)
- Dünnere Borders
- Leichtere Schriftgewichte
- Minimalistische Animationen

## Verwendung

Dieser Style wird geladen, wenn "Minimal" im Style-Dropdown ausgewählt wird.
