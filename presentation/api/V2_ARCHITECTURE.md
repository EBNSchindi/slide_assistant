# v2 API Architecture - New 3-Agent Pipeline

## Overview

The v2 API implements a completely redesigned architecture with three focused LLM agents and a deterministic HTML renderer:

```
User Input
    ↓
Agent 1: ContentAnalyzer
    ↓ (ContentBlocks + SlideIntent)
Agent 2: PresentationStrategist ←─┐
    ↓ (SlideBlueprint)             │ Feedback Loop
Agent 3: ContentGenerator ────────┘ (max 3 iterations)
    ↓ (FormattedSlide)
Renderer: HTMLComponentRenderer
    ↓
HTML + Markdown Output
```

## Key Design Principles

### 1. **LLM-Minimal HTML Generation**
- ✅ LLMs only handle: Understanding, Planning, Text Writing
- ✅ HTML is NEVER generated by LLM
- ✅ Fixed templates for all components
- ✅ Theme support is CSS-based, not LLM-based

### 2. **Clear Agent Responsibilities**

#### Agent 1: ContentAnalyzer
- **Input:** Raw user text
- **Output:** `SlideIntent` + `ContentBlock[]`
- **Job:** Understand what the slide is trying to say
- **File:** `agents/content_analyzer_v2.py`

#### Agent 2: PresentationStrategist
- **Input:** ContentBlocks + SlideIntent + Design System
- **Output:** `SlideBlueprint` (component layout plan)
- **Job:** Decide WHAT components to use, in what order
- **File:** `agents/presentation_strategist_v2.py`
- **Special:** Has `replan()` method for feedback loop

#### Agent 3: ContentGenerator
- **Input:** SlideBlueprint + ContentBlocks
- **Output:** `FormattedSlide` OR `ValidationResult` (for retry)
- **Job:** Write final text for each component
- **File:** `agents/content_generator_v2.py`
- **Special:** Validates content and provides feedback

#### Renderer: HTMLComponentRenderer
- **Input:** FormattedSlide
- **Output:** Complete HTML with CSS
- **Job:** Convert text to visual HTML (NO LLM)
- **File:** `renderers/component_renderer.py`
- **Features:** 7 component templates, theme support, image frames

### 3. **Intelligent Feedback Loop**

When Agent 3 detects content won't fit:

```
Agent 3: "This component has too many bullets"
    ↓
ValidationResult returned with feedback
    ↓
Agent 2: Gets feedback, replans layout
    ↓
Retry Agent 3 with new blueprint
    ↓
(Max 3 iterations before fallback)
```

## Component Types

All components are rendered via fixed templates:

| Type | Purpose | Max Content |
|------|---------|------------|
| `stat-grid` | Display statistics/metrics | 6 stats |
| `bullet-list` | Bullet points | 5-6 bullets |
| `quote` | Highlighted quote | ~100 words |
| `text` | Paragraphs | ~150 words |
| `image-frame` | Image with caption | 1 image |
| `process` | Sequential steps | 6 steps |
| `table` | Structured data | 5×5 max |

## Data Models (Pydantic)

All schemas in `schemas/blueprint.py`:

### ContentBlock
```python
{
  "type": "statistic|statement|bullet|bullets|quote|image_ref",
  "content": "Actual content text",
  "priority": "must_have|should_have|nice_to_have",
  "metadata": {}
}
```

### SlideIntent
```python
{
  "intent_type": "problem|solution|team|kpi|timeline|...",
  "primary_message": "One sentence summary",
  "language": "de|en",
  "density": "low|medium|high"
}
```

### ComponentBlueprint
```python
{
  "component_id": "comp-1",
  "type": "stat-grid|bullet-list|...",
  "position": "top|middle|bottom",
  "content_block_indices": [0, 1],
  "image_slot": {...} or null
}
```

### SlideBlueprint
```python
{
  "slide_title": "Title",
  "layout_type": "single|two_column|two_row|three_component",
  "components": [ComponentBlueprint, ...],
  "image_count": 1
}
```

### FormattedSlide
```python
{
  "slide_title": "Title",
  "components": [
    {
      "component_id": "comp-1",
      "type": "stat-grid",
      "title": "Component Title",
      "statistics": [{"label": "X", "value": "Y"}],
      "word_count": 45
    }
  ],
  "language": "de|en",
  "readability_score": "easy|medium|complex"
}
```

## API Endpoint

### POST `/api/v2/generate`

**Request:**
```json
{
  "project_name": "beispiel-projekt",
  "slide_number": 46,
  "user_input": "Raw slide content",
  "slide_title": "Optional title",
  "theme": "github|modern|minimal",
  "language": "de|en",
  "images": [
    {"filename": "team.png", "description": "Team photo"}
  ]
}
```

**Response:**
```json
{
  "success": true,
  "html": "...",
  "markdown": "...",
  "slide_blueprint": {...},
  "formatted_slide": {...},
  "iteration_count": 1
}
```

## Image Frame Standardization

All images are rendered in a consistent frame:

```html
<div class="image-frame">
  <h3 class="image-title">{title}</h3>
  <img src="{path}" alt="{alt_text}" class="frame-image" />
  <p class="image-caption">{caption}</p>
</div>
```

Features:
- Always consistent look across all images
- CSS-driven styling (no LLM involvement)
- Supports alt text for accessibility
- Optional caption and title

## Migration from v1

**Old v1 endpoint:** `/api/generate`

Both can coexist:
- v1 remains unchanged for backward compatibility
- v2 is the recommended new pipeline

## Performance Notes

### Typical Execution Time
- Agent 1 (Analyze): ~1-2 seconds
- Agent 2 (Plan): ~1-2 seconds
- Agent 3 (Generate): ~1-2 seconds
- Renderer (HTML): <100ms
- **Total:** ~3-6 seconds per slide (depends on LLM latency)

### Cost Optimization
- Use `gpt-4o` for balanced cost/quality
- Use `gpt-5-mini` for lower costs
- Mock agents for testing (0 API cost)

## Known Limitations

1. **Max 3 components per slide** - Design constraint
2. **Max 3 feedback iterations** - Prevents infinite loops
3. **Image paths are relative** - Must exist in project
4. **Language auto-detection** - Based on first block only
5. **No multi-slide generation** - One slide per request

## Troubleshooting

### "ImportError: No module named 'schemas.blueprint'"
- Make sure you're running from `presentation/api/` directory
- Verify `__init__.py` files exist in all subdirectories

### "ContentAnalyzerAgentV2 returns wrong format"
- Check that `use_structured_outputs=False` in config
- Verify Pydantic models imported correctly

### "Feedback loop keeps retrying"
- Check mock agents return valid `FormattedSlide`
- Verify `max_retries=3` in v2 endpoint

### "Image not appearing in HTML"
- Check `image_path` is relative to project
- Verify image file exists in project
